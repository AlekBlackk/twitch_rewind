# ⏪ Twitch Rewind

**Перематывайте живой стрим Twitch к началу, даже если запись (VOD) не опубликована.**

Twitch Rewind проигрывает DVR-плейлист, который Twitch записывает на свой CDN во время трансляции
(как строится ссылка, см. [`src/core/twitch.js`](src/core/twitch.js)). Откройте канал, нажмите на иконку расширения, и поверх
страницы появится окно плеера со списком эфиров канала, чатом и эмодзи.

> [!NOTE]
> Если Twitch не ведёт DVR для стрима, перемотка для него недоступна.

## ✨ Возможности

- **Перемотка живого стрима** к самому началу через DVR-плейлист, опубликованная запись не нужна.
- **Плеер в стиле Twitch**: пауза, громкость, полоса перемотки, «В эфир» (вернуться к прямой трансляции),
  меню качества («Источник (1080p60)» и перекодированные, выбор запоминается) и полноэкранный режим.
- **Клипы**: кнопка ✂ в плеере открывает окно «Создать клип»: предпросмотр, ползунки начала и конца
  (от 5 до 60 секунд) и название. Клип сохраняется в файл `.mp4` без перекодирования, границы идут по
  сегментам Twitch. Перед сохранением открывается окно «Сохранить как».
- **Повтор чата** рядом с видео: время отправки сообщений и эмодзи Twitch, 7TV, BTTV и FFZ
  (глобальные и канала).
- **Моменты по ключевым словам**: речь эфира (например, озвученные донаты) распознаётся на вашей видеокарте,
  а места со словами из вашего списка отмечаются на полосе перемотки. См. [ниже](#-моменты-по-ключевым-словам).
- **Список эфиров** плитками или строками, с поиском по названию, фильтром по периоду и сортировкой.
- **Любой канал**: введите имя или ссылку, подсказки подгружаются из поиска каналов Twitch по мере набора.
- **Отслеживаемые каналы**: плейлисты живых эфиров сохраняются в фоне, и стрим можно перематывать
  после его окончания.
- **Прошлые эфиры** с удалённой записью берутся с [sullygnome.com](https://sullygnome.com).
- **Подвижное окно**: перетаскивайте за заголовок, меняйте размер за правый нижний угол, сворачивайте
  до заголовка, воспроизведение при этом продолжается.

## 🚀 Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
4. Откройте канал на [twitch.tv](https://www.twitch.tv) и нажмите на иконку расширения.

Иконка ещё раз или ✕ закрывают окно, **—** сворачивает его до заголовка.

## 📼 Эфиры без записи

После окончания эфира у Twitch нет ссылки на его DVR, а время начала потом не восстановить.
Расширение обходит это двумя способами.

**Отслеживание канала.** Каждый канал, у которого вы нажали сердечко рядом с кнопкой «Поиск»
(кнопка «Поиск» только открывает записи введённого канала), проверяется раз в 5 минут, пока запущен Chrome. Ссылка на плейлист живого
эфира сохраняется в `chrome.storage.local` (около 300 байт, видео не хранится). После окончания стрима он
остаётся в списке с пометкой «сохранён расширением», пока Twitch держит DVR на своём CDN: подтверждено
2+ часа, дольше не измерялось. Удалённый эфир пропадает из списка.

- Эфир, который не видели в прямом эфире при открытом Chrome, сохранить нельзя.
- У сохранённых эфиров нет чата.
- Отслеживаемые каналы перечислены под панелью: клик по имени открывает канал, ✕ прекращает отслеживание
  (уже сохранённые эфиры остаются в списке). Пока открыт другой канал, «← имя» возвращает к каналу со
  страницы Twitch.

**Удалённые записи.** В список также попадают эфиры канала за последние 60 дней с sullygnome.com, где
известны id и время начала каждого стрима. Такой эфир называется «Эфир без записи». Его плейлист ищется на
CDN Twitch при открытии и находится, только пока Twitch его не удалил. Чата нет.

## 💬 Чат

| Эфир | Чат |
| --- | --- |
| Есть запись (в том числе пока она идёт) | Полный повтор чата |
| Прямой эфир без записи | Последние ~800 сообщений канала с [recent-messages.robotty.de](https://recent-messages.robotty.de) (сторонний сервис) и всё, что отправлено после открытия окна |
| Сохранён расширением или записи нет совсем | Чата нет |

Наведите курсор на время сообщения, чтобы увидеть время от начала эфира. Эмодзи загружаются при открытии окна.

## 🔎 Моменты по ключевым словам

Вкладка **Моменты** рядом с чатом: впишите слова и фразы, по одному в строке, выберите язык речи и нажмите
«Распознавать речь». Звук эфира распознаётся моделью [Whisper large-v3-turbo](https://huggingface.co/onnx-community/whisper-large-v3-turbo)
на видеокарте (WebGPU), текст сохраняется для эфира. Перед этим маленькая модель Silero VAD находит в звуке речь, и Whisper слушает только её: на музыке и шуме он придумывает слова. Найденные моменты отмечены на полосе перемотки и перечислены
с таймкодами, клик перематывает на 5 секунд раньше.

- Достаточно части слова: «дом» найдёт «домик» и «на доме». Короткий корень находит лишнее («кот» найдёт
  «который»). Регистр и «е»/«ё» не важны.
- Модель (~1,6 ГБ) скачивается с huggingface.co один раз и только после вашего нажатия, дальше хранится в
  браузере. Нужны Chrome с WebGPU и видеокарта с поддержкой fp16 (проверено на RTX 3090).
- Эфир распознаётся окнами по 5 минут с начала (у живого по минуте), пока открыто окно плеера. Слова стримера
  тоже попадут в список, если совпадут с вашими. Таймкод слова в длинной фразе точен до нескольких секунд.

## 🔒 Разрешения

| Разрешение | Зачем |
| --- | --- |
| `activeTab`, `scripting` | Вставить окно плеера во вкладку Twitch по клику на иконку |
| `storage`, `unlimitedStorage` | Хранить отслеживаемые каналы, сохранённые плейлисты, выбранное качество и распознанную речь эфиров |
| `downloads` | Показать окно «Сохранить как» при сохранении клипа |
| `wasm-unsafe-eval` (политика страниц расширения) | Запустить WebAssembly-рантайм модели распознавания речи |
| `alarms` | Проверять отслеживаемые каналы раз в 5 минут |
| `gql.twitch.tv`, `*.cloudfront.net` | API Twitch и CDN, на котором лежат DVR-плейлисты |
| `sullygnome.com` | Список прошлых эфиров |
| `recent-messages.robotty.de` | История чата для живых эфиров без записи |
| `7tv.io`, `api.betterttv.net` | Сторонние эмодзи |

## 🧪 Разработка

Сборки нет: расширение работает прямо из исходников. Тесты запускаются встроенным раннером Node.

```bash
npm test
```

| Файл | Назначение |
| --- | --- |
| [`src/background.js`](src/background.js) | Service worker: клик по иконке и опрос раз в 5 минут |
| [`src/overlay.js`](src/overlay.js) | Окно, вставляемое поверх страницы Twitch |
| [`src/core/twitch.js`](src/core/twitch.js) | Запросы к Twitch и ссылки на DVR-плейлисты |
| [`src/core/saved.js`](src/core/saved.js) | Сохранение плейлистов отслеживаемых каналов |
| [`src/core/quality.js`](src/core/quality.js) | Разбор качества и мастер-плейлист |
| [`src/core/clip.js`](src/core/clip.js), [`src/core/mp4.js`](src/core/mp4.js) | Скачивание сегментов клипа и сборка обычного mp4 (перемотка работает и в VLC) |
| [`src/core/chat.js`](src/core/chat.js), [`src/core/emotes.js`](src/core/emotes.js) | Повтор чата и загрузка эмодзи |
| [`src/core/`](src/core): `keywords.js`, `transcript.js`, `audio.js`, `vad.js`, `model-cache.js` | Моменты: поиск слов, окна и хранение распознанной речи, звук из сегментов, поиск речи, кэш модели |
| [`src/player/`](src/player) | Плеер и список эфиров (`player.html/.js/.css`), окно клипа (`clip-editor.js`), иконки; моменты: `moments.js` (вкладка и метки), `transcriber.js`, `whisper-worker.js` |
| [`test/`](test) | Тесты и образец видео для них (`fixtures/`) |

## 🙏 Благодарности

Воспроизведение построено на [hls.js](https://github.com/video-dev/hls.js), а сборка клипов в mp4 на
[mux.js](https://github.com/videojs/mux.js), распознавание речи на [Transformers.js](https://github.com/huggingface/transformers.js)
и [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) (оба в `vendor/`, `transformers.bundle.min.js` собран
esbuild из этих пакетов) с моделью Whisper от OpenAI. Эмодзи берутся из Twitch,
[7TV](https://7tv.app), [BetterTTV](https://betterttv.net) и [FrankerFaceZ](https://www.frankerfacez.com).
