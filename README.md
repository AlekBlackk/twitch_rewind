# ⏪ Twitch Rewind

**Перематывайте живой стрим Twitch к началу, даже если запись (VOD) не опубликована.**

Twitch Rewind проигрывает DVR-плейлист, который Twitch записывает на свой CDN во время трансляции
(как строится ссылка, см. [`src/core/twitch.js`](src/core/twitch.js)). Откройте канал, нажмите на иконку расширения, и поверх
страницы появится окно плеера со списком эфиров канала, чатом и эмодзи.

> [!NOTE]
> Если Twitch не ведёт DVR для стрима, перемотка для него недоступна.

## ✨ Возможности

- **Перемотка живого стрима** к самому началу через DVR-плейлист, опубликованная запись не нужна.
- **Плеер в стиле Twitch**: пауза, громкость, перемотка, «В эфир», меню качества (выбор запоминается),
  полноэкранный режим.
- **Клипы**: кнопка ✂ открывает окно «Создать клип» (до 60 секунд). Клип сохраняется в `.mp4` без
  перекодирования, границы идут по сегментам Twitch.
- **Повтор чата** рядом с видео, с эмодзи Twitch, 7TV, BTTV и FFZ.
- **Моменты по ключевым словам**: речь эфира (например, озвученные донаты) распознаётся на вашей видеокарте,
  а места со словами из вашего списка отмечаются на полосе перемотки. См. [ниже](#-моменты-по-ключевым-словам).
- **Список эфиров** плитками или строками, с поиском, фильтром по периоду и сортировкой, для любого канала
  (имя или ссылка, подсказки по мере набора).
- **Отслеживаемые каналы** и **прошлые эфиры** с удалённой записью (из [sullygnome.com](https://sullygnome.com)):
  см. [Эфиры без записи](#-эфиры-без-записи).
- **Подвижное окно**: перетаскивайте за заголовок, меняйте размер за правый нижний угол, сворачивайте
  до заголовка, воспроизведение при этом продолжается.

## 🚀 Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
4. Откройте канал на [twitch.tv](https://www.twitch.tv) и нажмите на иконку расширения.

Иконка ещё раз или ✕ закрывают окно, **—** сворачивает его до заголовка.

## 📼 Эфиры без записи

После окончания эфира у Twitch нет ссылки на его DVR, а время начала потом не восстановить.
Расширение обходит это двумя способами.

**Отслеживание канала.** Канал, у которого вы нажали сердечко рядом с «Поиск», проверяется раз в 5 минут, пока
запущен Chrome. Ссылка на плейлист живого эфира сохраняется в `chrome.storage.local` (около 300 байт, видео не
хранится). После окончания стрим остаётся в списке с пометкой «сохранён расширением», пока Twitch держит DVR
на своём CDN (подтверждено 2+ часа). Удалённый эфир пропадает из списка.

- Эфир, который не видели в прямом эфире при открытом Chrome, сохранить нельзя. У сохранённых эфиров нет чата.
- Отслеживаемые каналы перечислены под панелью: клик по имени открывает канал, ✕ прекращает отслеживание
  (сохранённые эфиры остаются).

**Удалённые записи.** В список попадают эфиры канала за последние 60 дней с sullygnome.com («Эфир без
записи»). Их плейлист ищется на CDN Twitch при открытии и находится, только пока Twitch его не удалил. Чата нет.

## 💬 Чат

| Эфир | Чат |
| --- | --- |
| Есть запись (в том числе пока она идёт) | Полный повтор чата |
| Прямой эфир без записи | Последние ~800 сообщений канала с [recent-messages.robotty.de](https://recent-messages.robotty.de) (сторонний сервис) и всё, что отправлено после открытия окна |
| Сохранён расширением или записи нет совсем | Чата нет |

Наведите курсор на время сообщения, чтобы увидеть время от начала эфира. Эмодзи загружаются при открытии окна.

## 🔎 Моменты по ключевым словам

Вкладка **Моменты** рядом с чатом: впишите слова и фразы, по одному в строке, выберите язык речи и нажмите
«Распознавать речь». Сначала модель Silero VAD находит в звуке речь, потом [Whisper large-v3-turbo](https://huggingface.co/onnx-community/whisper-large-v3-turbo)
распознаёт её на видеокарте (WebGPU), а текст сохраняется для эфира. Найденные моменты отмечены на полосе
перемотки и перечислены с таймкодами, клик перематывает на 5 секунд раньше.

- Достаточно части слова: «дом» найдёт «домик» и «на доме». Короткий корень находит лишнее («кот» найдёт
  «который»). Регистр и «е»/«ё» не важны.
- Модель (~1,6 ГБ) скачивается с huggingface.co один раз и только после вашего нажатия, дальше хранится в
  браузере. Нужны Chrome с WebGPU и видеокарта с поддержкой fp16 (проверено на RTX 3090).
- Эфир распознаётся окнами по 5 минут с начала (у живого по минуте), пока открыто окно плеера. Слова стримера
  тоже попадут в список, если совпадут с вашими. Таймкод слова в длинной фразе точен до нескольких секунд.

## 🔒 Разрешения

| Разрешение | Зачем |
| --- | --- |
| `activeTab`, `scripting` | Вставить окно плеера во вкладку Twitch по клику на иконку |
| `storage`, `unlimitedStorage` | Хранить отслеживаемые каналы, плейлисты, настройки и распознанную речь эфиров |
| `downloads` | Окно «Сохранить как» для клипа |
| `alarms` | Проверять отслеживаемые каналы раз в 5 минут |
| `wasm-unsafe-eval` (политика страниц расширения) | Запустить WebAssembly-рантайм распознавания речи |
| `gql.twitch.tv`, `*.cloudfront.net` | API Twitch и CDN, на котором лежат DVR-плейлисты |
| `sullygnome.com`, `recent-messages.robotty.de` | Список прошлых эфиров, история чата живых эфиров без записи |
| `7tv.io`, `api.betterttv.net` | Сторонние эмодзи |

## 🧪 Разработка

Сборки нет: расширение работает прямо из исходников. Тесты запускаются встроенным раннером Node.

```bash
npm test
```

| Файл | Назначение |
| --- | --- |
| [`src/background.js`](src/background.js) | Service worker: клик по иконке и опрос раз в 5 минут |
| [`src/overlay.js`](src/overlay.js) | Окно, вставляемое поверх страницы Twitch |
| [`src/core/`](src/core) | Логика без интерфейса: `twitch.js` (запросы, DVR-ссылки), `saved.js`, `quality.js`, `chat.js`, `emotes.js`, `clip.js` и `mp4.js` (клипы в обычный mp4), для моментов `keywords.js`, `transcript.js`, `audio.js`, `vad.js`, `model-cache.js` |
| [`src/player/`](src/player) | Плеер и список эфиров (`player.*`), окно клипа (`clip-editor.js`), иконки; для моментов `moments.js`, `transcriber.js`, `whisper-worker.js` |
| [`test/`](test) | Тесты и образец видео для них (`fixtures/`) |
